# EUROSIM 2026 汇报正式图绘制说明

本说明对应新版 PPT 中的 3 张正式图占位。PPT 保持文字简洁，正式图负责把结构关系、执行顺序和反馈闭环讲清楚。三张图分别回答三个问题：

1. 统一执行链路怎样组织；
2. 一个设备任务怎样完成一次执行；
3. 仿真怎样形成决策反馈闭环。

## 共用画法

- 位置：对应 PPT 第 8、9、10 页左侧占位区域；占位区域约为 735 × 390 px，宽高比约 1.88:1。
- 风格：白底、细线、扁平矢量图；颜色沿用 PPT：深蓝表示控制与结构，绿色表示状态/数据反馈，橙色表示约束触发，浅灰表示协议或环境。
- 字体：微软雅黑。图内主标签建议 18–22 pt，辅助说明不低于 14 pt；图在投影状态下也要能读清。
- 箭头：控制请求统一用蓝色实线向下或向右，状态/数据反馈统一用绿色实线向上或向左，约束触发用橙色虚线或侧向箭头。
- 图中只保留能帮助听众理解关系的标签，不要把所有字段、消息名和状态枚举都塞进图里。PPT 右侧文字已经承担解释作用。

## 正式图 1：统一执行链路（PPT 第 8 页）

### 要表达的结论

流程、人或大模型的意图，都进入同一套设备模型与状态机；状态机通过 Adapter 控制物理设备并接收反馈。约束观察整条链路并触发处理动作，不能形成一条绕过模型的旁路。

### 推荐构图

左侧画一条纵向执行链：

`工作流节点 → 设备模型（能力 + 状态机） → Adapter → 物理设备`

在这条主链右侧写出每层作用：

- 工作流节点：接口、数据端口、任务步骤；
- 设备模型：设备能力、属性、状态转移；
- Adapter：协议映射、命令下发、反馈转换；
- 物理设备：执行操作、产生测量和状态。

蓝色箭头沿主链向下，绿色箭头从物理设备沿原路返回到状态机和工作流节点。

在主链左上方标出 3 个意图来源：`人工`、`流程`、`大模型`。三者都指向“设备模型”的控制入口，箭头汇入同一点；不要从任何来源直接连到 Adapter 或物理设备。为避免产生“人工也必须先变成工作流节点”的误解，可以把三个来源画在共同入口旁边，标注“不同意图，共同执行入口”。

在主链右侧加一条约束观察线：`约束层 → 观察资源状态与工作流上下文 → 警告 / 报警 / 停止 / 中止`。处理动作要回到统一执行机制中，不能把约束画成简单的串行转发层。

### 图中建议保留的关键词

`能力模型`、`状态机`、`Adapter`、`物理设备`、`控制请求`、`状态反馈`、`共同执行入口`、`约束观察`。

## 正式图 2：加热任务执行时序（PPT 第 9 页）

### 要表达的结论

加热节点提出请求后，设备状态机经 Adapter 发令；物理设备产生温度和运行状态反馈，状态机根据完成条件推进节点。反馈到达不等于任务自动完成，节点要依据条件判断。

### 推荐构图

从左到右画 4 条生命线：

`加热节点 | 设备状态机 | Adapter | 反应釜`

从上到下画 6 个编号消息：

1. 加热节点 → 状态机：`请求加热`；
2. 状态机 → Adapter：`下发加热命令`；
3. Adapter → 反应釜：`执行加热`；
4. 反应釜 → Adapter：`温度 / 运行状态`；
5. Adapter → 状态机：`反馈更新`；
6. 状态机 → 加热节点：`执行状态`。

在第 6 步旁写一个小注释：`满足完成条件后，节点推进后续步骤`。把控制消息画成蓝色，把反馈消息画成绿色。不要把第 4 步画成“完成”，也不要把所有反馈都标为完成；完成由节点条件和约束共同决定。

在图右侧或下方增加一个橙色小分支：`温度越界 / 设备异常 → 按约束采取动作`，例如停止或报警。该分支回到状态机处理，不要直接连到物理设备。

## 正式图 3：仿真反馈闭环（PPT 第 10 页）

### 要表达的结论

仿真和实机只在 Adapter 层区分，上层继续使用同一套工作流、设备状态机和约束。大模型根据仿真反馈调整方案，满足预设条件后才进入实机执行。

### 推荐构图

上方放一个共同模型区：`工作流 + 设备能力/状态机 + 约束`。左侧放 `大模型决策`，下方放 `仿真 Adapter + 模拟设备/环境`。

用蓝色实线画主闭环：

`大模型决策 → 共同模型区 → 仿真 Adapter / 模拟环境 → 模拟反馈 → 大模型调整`

让“模拟反馈”回到大模型决策，形成明显的闭环箭头。可以在反馈旁标注 `状态、数据、约束结果`。

从共同模型区向右画一条分支，经过一个网关：`满足预设上机条件`，再连接到 `实机 Adapter → 物理设备`。仿真评估结果可以用绿色虚线指向该网关，表示它是上机判断依据；不要画成仿真 Adapter 直接向实机 Adapter 发送控制命令。

实机反馈沿共同模型区返回，用于保持模型状态和执行记录一致。图中明确写出 `仿真 / 实机共用上层模型与规则`，这样听众能看出扩展点在 Adapter，而不是另建一套控制逻辑。

## 与 PPT 文字的分工

第 4–7 页是模型定义和关键机制的文字说明，保持简洁即可；第 8–10 页的占位图才承担结构关系、时序关系和闭环关系。正式图替换占位框后，右侧三组短句和页脚结论可以保留，不需要再增加大段文字。
