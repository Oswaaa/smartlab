# EUROSIM 2026 汇报完整图包

共 7 张图，均包含彩色、黑白两套版本。每套有 SVG 矢量源文件和宽 4000 像素的 PNG。

1. 整体框架：展示 R、F、C 与 Π 的总体关系。
2. 资源层：直接复用并放大整体框架中的设备对象模型模块。
3. 工作流层：直接复用并放大整体框架中的流程与节点模块。
4. 约束层：复用约束模块，展开资源和工作流的观察、处理关系。
5. 统一执行链路：沿用已确定的版本，文件内容未修改。
6. 加热案例：五条生命线的简化时序，区分正常完成与异常处理。
7. 仿真闭环：共同模型、仿真调整和满足预设条件后的实机分支。

建议对应现有 PPT 的框架总览、三层介绍、关键机制、实现案例、扩展展望页面使用，无需新增主汇报页数。图承担关系表达，详细说明保留在演讲稿中。

SVG 可在矢量编辑工具中修改文字与线条；PNG 可直接插入 PPT。彩色版以蓝色表示控制、绿色表示状态和数据反馈、橙色表示约束处理；黑白版用实线和虚线区分。加热时序中的编号为讲解顺序，反馈在执行期间持续更新。仿真闭环是扩展方向图，不表示已完成实验验证。
