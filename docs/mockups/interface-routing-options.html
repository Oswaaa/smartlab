接口连线绕线方案

对照截图：device2 → end1、device1 → branch1 都从右边输出先向外再绕回节点上方。 下面「现状」复原这个往后绕；A–D 都改成先朝输入所在的节点走，再绕到左侧输入口。浅蓝细线是正常向前的执行流，不改。

现状 · 从输出往后绕过源节点

右口先再往右探一截，发现进不去就翻到节点顶上，整段横穿回去，最后才落到目标左侧。源节点被线包了一圈。

当前实现

方案 A · 先走到两节点缝隙，再从目标左侧进入

右口只出很短一截，马上向下走进 device 和 end 之间的空隙，横穿到目标左边，再落到输入口。不绕源节点顶。

A

方案 B · 贴墙走：源右墙下降，目标左墙上升

和 A 同一条思路，但更贴节点。出口/入口各约 8px，竖段几乎挨着卡片外沿，缝隙里的横段也更靠近下节点顶边。

B

方案 C · 先到达目标节点，再绕过目标外侧进入

线先下到 end1 所在这一层（到达输入节点），再从 end1 底边绕到左侧，向上送进输入口。绕的是目标，不是源。

C

方案 D · 输出立刻折向目标，不额外外探

右口不再先往右走。第一段就贴着源节点右缘向下（朝目标），再进缝隙、转到目标左缘。路径最短，折点最少。
