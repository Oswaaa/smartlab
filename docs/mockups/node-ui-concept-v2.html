节点 UI 概念设计 v2

在 v1「克制灰 + 状态色」基础上解决三个问题：端口数量用户自定义（节点随端口自适应）、连线风格二选一（平滑曲线 vs 圆角折线，两版同场景对比）、画布配套（网格 / 小地图 / 缩放控件）。

1执行口左右竖排、数据口上下横排，1~N 个都可以 2分支输出 = 一行一个条件标签，端口与行对齐 3形状分流派、颜色只表状态（沿用 v1） 4两版节点完全相同，只有连线和网格不同

版本 A · 平滑曲线Dify / n8n 风

贝塞尔曲线 + 点阵网格。柔和现代，交叉处不刺眼；device1 选中、device2 运行中、branch1 四个自定义输出、end1 两个执行输入。

连线为贝塞尔曲线，切线方向跟随端口朝向（左右口水平出、上下口竖直出）。数据流虚线同理。

版本 B · 圆角折线工程 / 组态风

正交折线（10px 圆角）+ 直线网格。横平竖直、像电路或工艺走线，走向好追踪；场景与版本 A 完全一致，便于对照。

连线为正交路由 + 圆角，中段走线自动让到独立通道（branch1 四个输出各占一条竖向通道，汇入 end1 时自然并线）。

动态端口

端口数量由用户配置决定：分支节点按输出行数自动长高，数据口在上下边均匀分布并带小标签。

曲线 vs 折线

版本 A · 平滑曲线版本 B · 圆角折线
气质现代 SaaS，Dify / n8n / Coze 同款工程工业，LabVIEW / 组态 / BPMN 同款
密集场景交叉处顺滑，但长距离走向不易追踪横平竖直好追踪，拐角太多时显乱
与数据流搭配虚线曲线依然柔和虚线折线像电路走线，和设备接线心智一致
与网格搭配点阵网格直线网格，折线自动对齐网格
实现成本贝塞尔，简单正交路由 + 圆角，需要简单的通道避让
我的建议：SmartLab 是实验室设备控制场景，用户是工程人员，主流执行流又是从左到右——版本 B（圆角折线）更贴合领域心智，对齐网格后整张图会非常工整。如果后续图经常很密集、斜向连接多，再切版本 A。两版节点和端口设计完全相同，连线风格可以做成可切换的。
