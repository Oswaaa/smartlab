节点 UI 概念设计

我的设计主张：形状区分流派，颜色只表达状态。整张画布默认全是中性灰，只有需要注意力的地方（选中、运行、成功、失败）才出现颜色——这是 AntD / Dify / n8n 共同的做法。

1圆形 = 控制口 · 实线 = 执行流；方形 = 数据口 · 虚线 = 数据流 2信息三层：类型图标 + 名称 → 操作 → 参数芯片 3类型色只给 26px 图标芯片，不上墙、不染线 4状态 = 左侧 3px 色条 + 右上角状态丸，不改结构

2. 状态矩阵

同一个设备节点的六种状态。结构完全不变，状态只通过左色条、状态丸、边框表达。
