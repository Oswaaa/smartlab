5.1 通信接口契约全景 (Interfaces & Signal Matrix)
共 6 个接口 · 18 个协议信号
接口标识 (Interface) 流向 / 方向 接口类型 允许信号集合 (Allowed Signals) 与语义说明
Interface_workflow_in IN (输入) WORKFLOW WF_EXECUTE_START (工作流启动指令) · WF_EXECUTE_ABORT (工作流中止指令)
Interface_control_in IN (输入) CONTROL MANUAL_EXECUTE_START (控制台手动启动) · MANUAL_EXECUTE_ABORT (控制台手动中止)
Interface_constraint_in IN (输入) CONSTRAINT CONSTRAINT_EXECUTE (约束闭环执行) · CONSTRAINT_ABORT (约束违规停机)
Interface_adapter_in IN (输入) ADAPTER COMMAND_RECEIVED · COMMAND_RUNNING · COMMAND_COMPLETED · COMMAND_FAILED · HEATING_STARTED · TARGET_TEMPERATURE_REACHED · COOLING_STARTED · TEMPERATURE_NORMAL
Interface_adapter_out OUT (输出) ADAPTER SEND · CMD_START (向驱动下发执行) · SEND · CMD_ABORT (向驱动下发终止)
Interface_state_out OUT (输出) STATE SEND · CMD_STATE (对外广播指令生命周期状态) · SEND · OP_STATE (对外广播业务功能状态)
