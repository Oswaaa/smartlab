共用画布。新建任务与运行状态都用设计器那一套：左右控制接口、上下数据端口、分支节点展示出口条件、正交折线。差异只在节点上的覆盖层——创建时是绑定状态，运行时是步骤状态。
浅蓝色从哪来。系统四级按钮里 .btn-aliyun-cta 本来是白底蓝边。任务约束面板在组件内覆盖成了 #eff6ff 浅底。效果图用规范 CTA：白底 + 主色描边，不要浅灰也不要浅蓝填充。
空状态不要灰底。约束空态去掉虚线灰盒，白底一段说明即可。步骤详情三块卡片同样去掉 #f8fafc，白底 + 细线分区。
接口快照仍是主体。每张接口卡先保留原来的信号名 + payload；触发器是卡片下方的附加层，默认 2 条摘要，其余折叠。不是用触发器替换快照。
