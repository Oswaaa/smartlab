控制接口“允许用户新增”的工业级交互解析

🌟 方案一：西门子工业双栏动态端子树 (Siemens / Schneider 风格 · 强烈推荐)

完美支持动态新增与全量平铺：

  • 左右分类与独立新增： 左侧是【输出接口】，头部有 [+ 新增输出] 按钮； 右侧是【输入接口】，头部有 [+ 新增输入] 按钮。用户想加哪类就点哪类，逻辑极度纯粹。
  • 动态扩容与删除： 新增的接口直接追加在列表下方； 系统预置接口标记为 系统，用户自定义接口显示 ✕ 删除按钮；
  • 全量平铺零遗漏：所有接口无论多少个，双栏内部平滑滚动，一眼纵览全局。

🌟 方案二：Camunda 端子卡片流 (末尾虚线新增)

低代码与流程编排标准：

  • 输出与输入分为上下两块；每一块末尾都有 [+ 新增接口] 虚线引导卡片；
  • 直观明了，适合卡片式网格。

🌟 方案三：Unreal / Blender 导轨式端子清单

蓝图与节点图工具标准：

  • 顶部带筛选器（全部 / 仅输出 / 仅输入）与右上角统一新增按钮；
  • 3 列紧凑网格展示。
