任务详情节点抽屉 UI 方案一优化 (单一方正合并框·父子层级清晰)

📐 方案一“单一方正合并框”重构落地点
1. 彻底合二为一 (Merged Single Box)

合并优化将原本散落的“当前信号快照”与“关联触发器规则”彻底合并为一个四四方方的直角容器 (.s1-unified-box)，不再有两张零散的小卡片，界面高度集约。

2. 严密的父子层级表现体系

父子分明通过三重手段确保父子关系 100% 直观明确：

• 左侧 18px 深度缩进：合并框整体挂在接口下方并向右缩进；

• 浅灰树形导轨线 (border-left: 2px solid #cbd5e1)：将接口主干与合并框物理连接；

• 字阶梯次：接口名 12.5px 粗体 ➔ 子段落标 11px ➔ 参数 11px mono。

3. 朴素直角规范 (All Straight Angles)

零圆角规范全局强制 border-radius: 0，零胶囊药丸，纯方正直角线条。

4. 接口标题彻底去信号

纯净标题接口标题行右侧不显示任何信号文本，纯净干练。

5. 数据端口：纯白通栏直角表格

纯白直角纯白背景、直角 1px 细线边框的标准 4 列数据表格。
