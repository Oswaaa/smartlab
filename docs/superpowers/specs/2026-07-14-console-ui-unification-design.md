# SmartLab 控制台 UI 统一设计

## 目标

在不改变现有业务能力和接口契约的前提下，统一设备模型、设备实例、Adapter、流程设计、任务列表、数据中心和用户管理七个页面，使其成为同一套面向实验室运营人员的企业级控制台。

## 调研依据

- Ant Design 数据展示原则：按重要性、操作频率和关联程度组织内容；结构化数据以表格、搜索、筛选和分页协同呈现。
- Ant Design 详情页原则：信息尽量扁平展示，按邻近关系分组，减少不必要折叠和结构差异。
- 腾讯云物联网控制台：产品/设备列表负责定位对象，详情页分区呈现状态、物模型、日志与调试能力；危险操作不作为首要动作。
- 阿里云 IoT Platform：设备模型、设备、在线调试、日志和任务按资产生命周期分区，配置与运行态分离。
- AWS Workflow Studio：节点库、画布、属性检查器三栏结构，通用操作集中在画布工具栏，配置围绕当前选中节点展开。

## 产品原则

1. **对象优先**：先选择类别、模型、实例或 Adapter，再查看详情和执行操作。
2. **主次明确**：每个页面只保留一个高亮主操作；刷新、导出、删除等进入次级层级。
3. **高信息密度**：取消大面积装饰卡片、玻璃拟态、渐变文字和无业务意义留白。
4. **配置与运行分离**：静态契约、运行状态、绑定关系、日志/历史分别呈现。
5. **渐进披露**：列表显示识别和决策所需字段，完整配置放在详情、抽屉或标签页。
6. **一致反馈**：成功、运行、等待、失败使用同一组颜色和标签语义；空值统一显示 `-`。
7. **危险操作收敛**：删除、终止等动作使用文字按钮或更多菜单，并保留二次确认。

## 统一视觉规范

- 页面背景 `#f5f7fa`，内容背景 `#ffffff`，边框 `#e5e7eb`。
- 主色 `#1677ff`；成功 `#16a34a`；警告 `#d97706`；危险 `#dc2626`。
- 使用系统中文字体栈，不依赖远程字体。
- 页面标题 20px/600，区块标题 14px/600，正文 14px，辅助信息 12px。
- 控件高度以 32px 为主；表头 13px，不使用全大写字母。
- 圆角 6px；只在浮层使用明显阴影，常规内容依赖边框分区。
- 左侧资产栏宽度统一在 300–320px；编辑抽屉保持统一宽度和可滚动结构。

## 页面结构

### 设备模型、设备实例、Adapter、数据中心

采用固定高度的左右工作台。左侧负责搜索和对象选择；右侧顶部显示当前对象、摘要和主操作；正文以标签页、数据表格或详情分组展示。

### 流程设计

保持节点库—画布—检查器结构。取消悬浮玻璃标题和节点上浮动画，工具栏固定、画布最大化；节点颜色只表达节点类别与选中状态。

### 任务列表、用户管理

采用“页标题与主操作—状态/筛选工具栏—数据表格—分页”结构。行点击进入详情，行内仅保留高频操作，危险动作降低视觉权重。

## 业务交互要求

- 创建动作完成后刷新目标列表并选中新对象。
- 搜索位于其影响的数据集合旁，不放在全局无关区域。
- 后台静默轮询不得触发整页 loading；详情轮询只更新局部数据。
- 抽屉正文独立滚动，标题和底部操作固定。
- 表格时间、状态、操作列不换行；长标识符省略并提供完整查看能力。
- 空状态同时说明当前原因和下一步可执行动作。

## 验收标准

- 七个页面具有一致的标题、间距、表格、状态和操作层级。
- 主要功能入口和现有 API 调用保持不变。
- 1280px 桌面宽度无横向页面溢出；窄屏下侧栏和工具栏可合理收缩。
- 前端生产构建通过，并对关键路由进行截图审查。
