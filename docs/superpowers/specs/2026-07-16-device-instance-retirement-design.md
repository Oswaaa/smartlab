# 设备实例注销设计

## 目标

用 `DEVICE_INSTANCES.LIFECYCLE_STATUS` 表达设备实例是否可参与业务。状态固定为 `使用中`、`已注销`；注销不可逆且不删除实例、孪生快照、数据集、组件拓扑或历史日志。

## 业务边界

- 新实例固定写入 `使用中`。
- 注销仅把实例改为 `已注销`，保留 Adapter 绑定字段作为历史，但立即从运行时路由中移除。
- 可用性在业务资源入口判断：实例编辑、手动控制、任务绑定及执行、数据集创建、组件配置与绑定。状态机不解释资产生命周期。
- 已注销实例允许查询详情、孪生快照、数据、组件拓扑及历史，不允许任何产生新业务状态的操作。
- 组件保持 `使用中/待更换/已更换` 原状态；父实例注销后整棵拓扑只读。`self_instance_id` 指向的独立实例不级联注销。
- 已注销实例不进入 Adapter 路由；来自其原设备点的新遥测和事件不再映射到该实例。

## API 与界面

- `POST /api/device/instance/retire/{id}` 注销实例。
- 物理删除接口取消业务能力。
- 列表和分页支持 `lifecycleStatus` 过滤；历史展示可查询全部，资源选择器只请求 `使用中`。
- 设备实例页提供“使用中/已注销”筛选；已注销详情只读，隐藏或禁用编辑、控制、组件操作和数据集创建。

## 数据约束

- 本次只记录 `LIFECYCLE_STATUS`，不向 `INSTANCE_CONFIG` 塞入注销原因、时间或操作人。
- 注销时若当前指令状态不是 `IDLE`，拒绝注销，避免物理动作仍在运行时切断业务控制链。
