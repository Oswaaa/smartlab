# SmartLab 组会 HTML 演示稿设计

## 目标

为导师与同学制作一份约 10 分钟的中文组会演示稿，解释“任务导向的可执行建模框架”如何在 SmartLab 2.0 中落地。

## 叙事

听众应理解：SmartLab 的关键贡献不是管理更多设备，而是以任务为中心统一描述设备能力、运行状态、约束条件、通信协议与工作流，使实验过程能够被配置、执行、监控和追溯。

叙事按“问题 - 框架 - 落地 - 闭环 - 价值”推进，共 11 页：封面、研究问题、核心观点、六类模型、模型关系、系统映射、任务闭环、执行机制、当前成果、研究价值、总结与下一步。

## 体验与边界

- 产物为单一离线 HTML 文件，不依赖网络或构建工具。
- 面向 16:9 投影，中文优先；每页保持一个主要结论。
- 通过左右方向键、空格、鼠标点击和底部进度条翻页；支持 `Home`/`End`。
- 使用 CSS/SVG 结构图呈现关系，不夸大尚未验证的实验指标。
- 新文件写入 `output/html/`，不改动现有系统代码。
