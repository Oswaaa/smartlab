# 流程设计器连续控制台界面设计

## 目标

在不改变流程模型、节点业务逻辑和接口协议的前提下，将流程设计页面统一为阿里云控制台式连续工作台，提升流程编排、属性查看和节点配置的可读性与操作效率。

## 页面结构

- 左侧为节点资源面板，固定宽度约 218 像素，使用分组列表、资源树和细高亮线表达选中状态。
- 中间为流程画布，占据剩余空间，工具栏、画布和底部状态区连续排列。
- 右侧为流程属性检查器，固定宽度约 304 像素，只展示流程级基本配置、静态建模检查和流程统计。
- 三栏之间不使用卡片间距，通过单像素分隔线建立层级。

## 节点抽屉

- 最大宽度由 1120 像素缩减为 960 像素，最小宽度为 820 像素，小屏幕使用全宽。
- 标题、节点统计条、配置标签页和配置内容使用连续白色背景。
- 节点统计条与抽屉边缘、配置详情之间不得出现灰色背景空隙。
- 删除节点位于标题区右侧，保持低频危险操作的弱强调样式。
- 所有装饰性英文标题删除，界面说明统一使用中文。

## 控制接口和触发器

- 控制接口采用左侧接口列表、右侧接口详情与触发规则的主从布局。
- 触发器使用“当……则……”规则行，不使用三个等宽输入框平铺。
- 条件对象宽约 210 像素，操作符宽约 92 像素，阈值宽约 156 像素。
- 动作类型宽约 116 像素，动作目标宽约 224 像素，动作值宽约 180 像素。
- 系统默认接口与触发器保留只读边界；功能节点的自定义接口和触发器保持可编辑。

## 节点、连线和画布

- 节点宽度约 178 像素，采用紧凑标题栏和内容区，选中时显示阿里蓝描边与轻量外环。
- 工作流接口使用蓝色圆形锚点，数据端口使用紫色方形锚点，颜色同时通过形状区分。
- 执行流使用蓝灰色实线和箭头，数据流使用紫色虚线；选中连线使用阿里蓝或对应数据色增强。
- 画布使用浅灰底和 16 像素点阵网格，减少阴影和圆角。

## 配色和动效

- 主色：`#1677ff`；悬停：`#4096ff`；浅选中背景：`#e6f4ff`。
- 页面底色：`#f5f5f5`；内容面：`#ffffff`；分隔线：`#e5e5e5`。
- 主文字：`#262626`；次要文字：`#595959`；辅助文字：`#8c8c8c`。
- 成功、警告和错误只用于表达状态，不作装饰。
- 悬停和选中反馈使用 150 毫秒；抽屉进入退出使用 200 毫秒；禁止弹跳和大幅位移。

## 验收标准

- 页面三栏、节点抽屉各区域之间无异色空隙。
- 流程级设置始终位于右侧属性栏，节点设置始终位于抽屉。
- 用户可一眼识别控制接口、数据端口、执行流和数据流。
- 触发器字段宽度与数据长度相符，窄屏下按行折叠。
- 页面固定文案不出现英文装饰标题。
- 现有流程设计结构测试、前端完整测试和生产构建全部通过。
