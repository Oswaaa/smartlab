# 工作流画布 UI 优化设计

## 目标

解决画布节点在接口、端口增多时内容重叠的问题，让资源侧边栏与设备模型页面保持一致，并让自动布局和连线路由更符合流程图阅读习惯。

## 范围

- 修改工作流设计器画布节点、资源侧边栏、画布背景和连线视觉。
- 修改前端自动布局算法。
- 不修改工作流模型、接口连接规则、端口连接规则或后端执行逻辑。
- 不创建分支，不自动提交或推送。

## 节点结构

画布节点采用“主体 + 四向连接轨道”结构：

- 左侧为 WORKFLOW 输入接口，右侧为 WORKFLOW 输出接口。
- 上方为数据输出端口，下方为数据输入端口。
- STATE 接口继续只存在于节点配置抽屉，不出现在画布。
- 节点主体显示节点类型、节点名称和一行业务摘要。
- 设备能力节点摘要优先显示能力显示名称，其次显示能力标识，并显示已配置参数数量。
- 接口和端口在画布上只显示连接点，不常驻显示名称或短标识；完整信息只在悬停连接点时通过脱离节点布局的提示浮层显示。
- 接口数量决定节点高度，端口数量决定节点宽度；使用统一尺寸计算函数，布局算法和节点组件共享同一结果。

节点基础宽度为 220px、基础高度为 92px。接口按不小于 22px 的纵向间距排列，端口按不小于 34px 的横向间距排列。连接点定位层不渲染任何参与排版的文字，节点主体只显示节点信息；节点尺寸随连接点数量增长，避免连接点过密。

## 资源侧边栏

设备库采用与设备模型页面一致的紧凑树形导航：

- 层级为“类别 → 模型 → 实例”。
- 行高 34px，使用文件夹、文档、设备图标。
- 去掉整块卡片、彩色“模型/实例”标签和大行距。
- 悬停使用浅灰背景；当前项使用浅蓝背景和左侧 3px 蓝色指示条。
- 模型右侧显示实例数量，实例右侧显示“设备实例”。
- 搜索栏、树缩进、字号和颜色沿用设备模型树的视觉规范。

流程库复用相同的树行结构：状态分组使用文件夹图标，流程使用文档图标，当前流程使用左侧蓝条和“当前”轻量文字标识。

## 连线视觉

- 执行流使用低饱和蓝灰色实线，数据流使用紫色虚线。
- 默认线宽 1.6px，悬停或选中时提高到 2.4px 并增强颜色。
- 使用平滑正交路径，节点出口和入口保留至少 24px 的水平或垂直直线段。
- 降低默认阴影和装饰，避免大量连线时画布过重。
- 画布网格使用更浅的 20px 点阵背景。

## 自动布局

新增纯函数 `buildWorkflowAutoLayout(nodes, interfaceConnections, portConnections)`：

1. 将节点连接转换为有向图，执行流连接优先，数据流连接也参与层级约束。
2. 使用 Kahn 拓扑遍历计算节点层级；存在环时将未处理节点放入后续层，保证函数总能返回布局。
3. 同层节点按照上游节点的重心排序，减少交叉。
4. 每层横向位置根据该层之前的最大节点宽度计算；同层纵向位置根据每个节点实际高度累加。
5. 层间距不小于 150px，同层节点间距不小于 72px。
6. 每层整体垂直居中，使分支展开、汇聚收拢。
7. 自动布局完成后刷新节点连接点并居中适配画布。

## 交互与异常处理

- 节点选中、配置警告、悬停状态沿用现有语义，只更新视觉层级。
- 超长节点名和能力名称保持单行省略，完整内容通过原生标题提示查看。
- 接口提示显示方向、完整接口名；端口提示显示方向、完整端口名和绑定变量的数据类型，提示内容挂载到节点布局之外。
- 没有连接或存在环的流程仍可自动布局，不弹错误。
- 修改接口或端口后刷新 Vue Flow 节点内部尺寸，连线端点立即跟随新位置。

## 验证

- 单元测试覆盖节点尺寸、DAG 分层、分支/汇聚、断开节点和环路回退。
- 结构测试覆盖四向连接轨道、悬停完整名称、紧凑资源树和连线视觉约定。
- 运行完整前端测试和生产构建。
